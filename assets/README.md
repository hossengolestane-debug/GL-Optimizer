# Assets

The product mark is monochrome: background `#0A0A0A`, foreground `#FFFFFF`.

- `mark.svg` is the source drawing: a geometric G and an L, not a wordmark and not the GameLoop logo.
- `AppIcon.ico` is the Windows executable, window, and tray icon (16, 32, 48, and 256 px).

Do not add accent colors, neon, or RGB lighting to the brand.
